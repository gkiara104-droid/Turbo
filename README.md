# Turbo 🐱
App web (PWA) para controlar tu dinero puntual: becas, cumpleaños, regalos…

## Subir a GitHub y usar en Android
1. Crea un repositorio y sube todos estos archivos a la raíz.
2. Settings → Pages → Branch `main` / carpeta `/ (root)` → Save.
3. Abre `https://TU-USUARIO.github.io/NOMBRE-REPO/` en Chrome del móvil.
4. Menú ⋮ → **Instalar aplicación** (o “Añadir a pantalla de inicio”).

Los datos se guardan en el móvil. Usa Ajustes → Descargar para hacer copia.
